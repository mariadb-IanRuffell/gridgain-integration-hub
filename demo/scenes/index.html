What the demo showed

  • Sybase and Oracle changes reach GridGain within about a second, and every table matches its source
  • Eleven stored procedures run as compute jobs with identical results: 16 + 30 parity checks
  • Customer data from both systems joins on one node: queries and APIs neither system could offer
  • A 3-node persistent cluster loses a node, keeps serving, and rejoins with its data
Sybase ASE runs on a Linux server (this 2015 build cannot run on an Apple Silicon Mac); Oracle runs locally in Docker
